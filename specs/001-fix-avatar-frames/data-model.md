# 阶段 1 数据模型: 修正生成武将头像的八帧表情

日期: 2026-08-28

## 实体 1: 头像表情条（avatar sheet）

游戏内武将默认头像的唯一资产形态，每名武将一个文件。

| 字段 | 值 | 说明 |
|---|---|---|
| 路径 | `bwdl/packed/images/actor/face/avatar/{ID}.png` | ID = actors.json 武将 ID |
| 尺寸 | 256×40，RGBA | 8 帧横排，每帧 32×40 |
| 帧序 | `[怒闭, 怒张, 喜闭, 喜张, 平闭, 平张, 哀闭, 哀张]` | 即帧 i：mood=i//2，mouthFlag=i%2 |
| 加载方 | `Actor_Helper.gd:1126` 直连加载 | 不经 resource→packed 重写 |
| 取帧方 | `actor_face.gd:100` `mood*2*W + mouthFlag*W` | 运行时契约，不可变 |

**验证规则**（对应 FR）：
- 尺寸必须 256×40（FR-001）
- 帧 4 与修复前逐像素一致（FR-003）
- 同心情闭/张两帧：仅嘴区（眼底线+1 ~ +5，宽 6~26）允许差异，其余逐像素一致（FR-004）
- 全部像素 ∈ 原帧 4 颜色集合（FR-006）
- 8 帧不全同；至少含 4 种可区分眼区形态（FR-001/FR-002）

## 实体 2: 五官定位（face features，运行时派生，不落盘）

从帧 4 检测出的几何特征，是表情变换的输入。

| 字段 | 类型 | 检测方式 | 实测命中率 |
|---|---|---|---|
| eye_top / eye_bottom | int（行 12~24） | 暗色像素（r+g+b<180）峰值行上下扩展 | 2002/2002 |
| mouth_y | int（行 eye_bottom+2 ~ 33） | 宽 3~12 的暗色横段；缺失时兜底 eye_bottom+3 | 1774/2002，兜底 228 |
| mouth_visible | bool | 兜底位置周围 5×14 窗口暗色占比 > 0.6 → 判为胡须遮挡，跳过嘴变形 | — |

## 实体 3: ID 段与处理策略

| ID 段 | 数量 | 处理 | 依据 |
|---|---|---|---|
| 0~545 | 546 | 跳过（原版已合规） | FR-007 |
| 546 | 1 | 跳过（「自定义」灰占位，8 帧全同属设计） | spec 边缘情况 |
| 547~560 | 14 | 跳过（原版已合规） | FR-007 |
| 561~2562 | 2002 | 修复（从帧 4 派生 7 帧） | FR-001 |
| 2563+ | — | 不在本次范围；校验时报告缺失 | R8 |

## 实体 4: 工具模块契约

| 模块 | 职责 | 关键接口（中文注释） |
|---|---|---|
| `expressions.py` [新增] | 五官检测 + 表情派生（核心逻辑，必测） | `locate_features(frame4) -> Features`；`derive_sheet(frame4) -> 256×40 Image`；`derive_frames(frame4) -> [8×32×40 Image]` |
| `fix_all_frames.py` [新增] | 存量批量修复入口 | `--dir <avatar目录> --dry-run`；只处理 561~2562；原子写（.tmp→替换）；输出统计 |
| `check_frames.py` [新增] | 全库合规校验 | `--dir <avatar目录>`；输出：八帧全同清单、尺寸异常、缺文件（如 2563）；退出码非 0 = 有违规（546 白名单除外） |
| `avatar_composer.py` [修改] | `to_sheet()` 复制 8 帧 → `expressions.derive_sheet(frame)` | 其余签名/调用方不变 |

**状态转换**（单张头像生命周期）:

```
全同 8 帧(现状) --fix_all_frames(从帧4派生)--> 合规 8 帧
合规 8 帧 --fix_all_frames 重跑--> 合规 8 帧（逐字节不变，幂等）
任意状态 --check_frames--> 报告（全同清单/缺失/尺寸异常）
新武将生成 --avatar_composer.to_sheet--> 合规 8 帧（防复发）
```
