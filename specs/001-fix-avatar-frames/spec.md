# Feature Specification: 修正生成武将头像的八帧表情

**Feature Branch**: `001-fix-avatar-frames`

**Created**: 2026-08-28

**Status**: Draft

**Input**: User description: "在bwdl/packed/images/actor/face/avatar 里面存放了每个武将的头像，每个图片是包含8副图，你先通过代码调研一下这8个图分别是什么场景什么表情，然后我需要你帮我重新生成我自定义的人物的图片，原版只有560多个人物，后面的人物都是我加的，然后通过tools/avatar_gen生成的，但是这个生成有Bug，导致生成的8个头像其实是复制的一模一样，不是不同场景下的表情，需要修正后续的这些名人的头像。"

## 背景调研结论（代码实证）

八帧表情条的布局与用途已从游戏代码中确认：

- 渲染逻辑（`bwdl/windows/children/actor_face.gd:100`）：帧横坐标 = `心情 × 2 × 帧宽 + 嘴型标志 × 帧宽`，即 **4 种心情 × 2 种嘴型 = 8 帧**，每帧 32×40，整条 256×40。
- 心情取值 0~3，语义由游戏对话用法实证：
  - **心情 0 = 愤怒**（如搜访被拒「某虽不才，不事无义之主！」）
  - **心情 1 = 高兴**（如搜索成功、计谋得逞的报告）
  - **心情 2 = 默认/平静**（绝大多数对话框的缺省值）
  - **心情 3 = 沮丧**（如「非常可惜，并无值得一提之事」、计谋失败）
- 播放逻辑（`actor_face.gd:64`）：说话时闭嘴↔张嘴交替，每两拍心情 +1 循环——形成「边说边变表情」的动画。
- 原版三国头像（ID 0~560）的 8 帧两两不同：同一心情的闭嘴/张嘴仅嘴部不同，不同心情靠**眉毛与眼睛的形态**区分（愤怒皱眉瞪眼、高兴眯眼、平静平眼、沮丧垂眉垂眼）。
- Bug 根因：批量生成工具把同一张 32×40 单帧原样复制 8 次填满整条，导致 ID 561~2562 共 **2002 张**生成头像在任何场景下表情纹丝不动，嘴型动画与心情切换双双失效。
- 特例：ID 546（「自定义」灰色占位图）8 帧全同属设计使然，**不在修复范围**。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 对话表情随剧情变化 (Priority: P1)

玩家在游戏中与扩展武将（ID 561 及以后，如历代名人）对话时，武将头像应随对话语境呈现不同表情：报告好消息时高兴、失败时沮丧、被拒绝时愤怒、平常对话时平静，而非始终一张静止的脸。

**Why this priority**: 这是本功能的直接目标——扩展武将的表情表现与原版三国武将一致，是视觉体验的核心缺口。

**Independent Test**: 触发任意扩展武将的对话（如搜索到宝物、计谋失败），观察头像表情是否随语境变化。

**Acceptance Scenarios**:

1. **Given** 一名扩展武将（ID ≥ 561），**When** 其头像图被载入游戏，**Then** 8 帧中至少存在 4 种可区分的表情（愤怒/高兴/平静/沮丧）。
2. **Given** 一名扩展武将，**When** 对话语境为好消息（心情 1），**Then** 显示的脸部表情与坏消息（心情 3）时可见地不同。
3. **Given** 任意扩展武将的默认外观，**When** 与修复前对比，**Then** 平静-闭嘴帧（第 5 帧）的容貌保持不变——玩家熟悉的这批名人长相不被改变。

---

### User Story 2 - 说话嘴型动画正常 (Priority: P2)

玩家观看任意扩展武将的对话时，头像应有闭嘴↔张嘴的交替动画（与原版武将一致），而非一张永远闭着（或张着）嘴的静止图。

**Why this priority**: 嘴型动画是游戏对话的基础表现，缺失时明显违和；但依赖用户故事 1 的帧结构先修好。

**Independent Test**: 观察任意扩展武将的长对话，头像嘴部是否有开合变化。

**Acceptance Scenarios**:

1. **Given** 一名扩展武将，**When** 对话播放说话动画，**Then** 同一心情下闭嘴帧与张嘴帧交替出现。
2. **Given** 任意一张修复后的头像，**When** 逐帧检查，**Then** 每对心情帧（闭嘴/张嘴）之间仅嘴部区域不同，其余部分逐像素一致。

---

### User Story 3 - 风格与原版统一 (Priority: P3)

玩家不会察觉扩展武将头像与原版三国头像的制作方式差异：表情变化方式（哪些五官变动、变动幅度）应与原版三国头像的惯例一致，色板不越界，游戏加载不报错。

**Why this priority**: 保证修复后的 2002 张图融入整体美术风格，属质量收尾。

**Independent Test**: 将修复后的头像与原版头像并排逐帧对比，检查表情变化模式与色板一致性。

**Acceptance Scenarios**:

1. **Given** 修复后的全部头像，**When** 程序化批量检查，**Then** 每张为 256×40、8 帧、仅使用游戏主色板内颜色。
2. **Given** 修复后的头像，**When** 与原版头像的表情帧对比，**Then** 各心情的五官变化模式（眉/眼/嘴）与原版惯例方向一致。

---

### Edge Cases

- ID 546（「自定义」灰色占位）8 帧全同是设计使然，修复流程 MUST 跳过，不得误改。
- 个别生成头像若眉眼区域过小或被头饰遮挡，表情派生不明显时，至少保证嘴型开合两帧可见差异。
- 修复过程 MUST 可重复执行（重跑不叠加变形、不劣化画质），且只动 561~2562 段，不碰 0~560 原版段。
- 未来新增武将（ID 2563+）走生成流程时，产出的头像 MUST 直接符合八帧规范，不再复现此 Bug。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 将 ID 561~2562 的全部 2002 张生成头像重新制作为符合「4 心情 × 2 嘴型」的八帧表情条。
- **FR-002**: 每张头像的帧序 MUST 为：帧 0/1=愤怒（闭/张嘴）、帧 2/3=高兴（闭/张嘴）、帧 4/5=平静（闭/张嘴）、帧 6/7=沮丧（闭/张嘴），与游戏渲染代码的取帧公式一致。
- **FR-003**: 每位武将的「平静-闭嘴」帧 MUST 与修复前该头像的现有画面保持一致（容貌不变，仅补齐其余 7 帧）。
- **FR-004**: 表情差异 MUST 通过对眉、眼区域的修改实现，嘴型差异通过口部开合实现；同一心情的闭/张嘴两帧除嘴部外 MUST 逐像素一致。
- **FR-005**: 表情的五官变化模式 MUST 参照原版三国头像（ID 0~560）的惯例（愤怒皱眉瞪眼、高兴眯眼、沮丧垂眉垂眼），保持画风同源。
- **FR-006**: 修复后的头像 MUST 仍使用游戏 64 色主色板，不得引入色板外颜色。
- **FR-007**: 修复流程 MUST 可幂等重跑，且 MUST 跳过 ID 0~560 原版段与 ID 546 灰色占位。
- **FR-008**: 修复 MUST 提供批量校验手段：能一键报告全部头像中「八帧全同」的残留数量，修复后该数量为 0（546 除外）。
- **FR-009**: 生成工具本身 MUST 同步修正，使后续新武将的批量生成直接产出合规八帧，杜绝复发。
- **FR-010**: 修复后的全部头像 MUST 能被游戏正常加载（headless 校验通过，无加载报错）。

### Key Entities *(include if feature involves data)*

- **头像表情条**：256×40 横条 PNG，8 个 32×40 帧，按「心情 0~3 × 嘴型闭/开」排列；每名武将一个文件，按武将 ID 命名。
- **心情（0~3）**：愤怒 / 高兴 / 平静 / 沮丧，由游戏对话系统按语境传入。
- **武将 ID 段**：0~560 原版（已合规）；546 灰占位（跳过）；561~2562 生成段（本次修复对象）；2563+ 未来增量。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 全库 2563 张头像中，「八帧全同」的头像数量从 2002 降为 1（仅剩 ID 546 设计占位）。
- **SC-002**: 任意扩展武将在游戏对话中呈现至少 4 种可区分表情，说话时嘴部有开合动画，与原版武将行为无差异。
- **SC-003**: 全部 2002 张修复头像的「平静-闭嘴」帧与修复前逐像素一致（容貌零改变）。
- **SC-004**: 批量校验可在 1 分钟内完成全库检查并输出合规报告；游戏 headless 加载校验无报错。

## Assumptions

- 表情帧采用**程序化派生**（以每张现有默认帧为基底，按原版惯例修改眉/眼/嘴区域），而非重新随机拼合——确保名人容貌不变。
- 嘴型「张开」的画法参照原版张嘴帧的口部形态（张口露深色口腔），不改变下颌轮廓。
- 原版段 ID 0~560 的表情变化规律可作为全段统一模板（个别武将若眉眼特征特殊，以不破坏其特征为前提套用）。
- 本修复只涉及头像图片资产与生成工具，不改动任何游戏运行时代码。
