# 历代状元表（唐—清，文/武）

> 说明
> - 本表收录自唐（状元称谓之始）至清末（1904 年最后一科，1905 年废科举）历朝文、武状元。
> - 字段：姓名 / 字 / 出场(约) / 卒年(约) / 身份 / 出处 / 体 / 武 / 知 / 忠 / 德 / 政 / 统 / 胆 / 军种。出场(约) = 首次见诸史书（有明确事迹）的年份，非出生年；不详者标 `?`；无独立字者字列标 `?`。
> - 出处以正史为主（《旧唐书》《新唐书》《旧五代史》《宋史》《辽史》《金史》《元史》《明史》《清史稿》及《登科记考》）；若人物已收录于 bwdl/packed/data/actors.json（其他朝代文件），身份列标注「已存在」。
> - 能力估值范围 1—99（忠可到 100）；军种：平（平地）、山（山地/骑射野战）。文状元军种「平」，武状元军种「山」。文状元「知」按 90 起步分档：普通 90 / 名臣·文学家 91-93 / 宰相·三元 94-96；武状元「体」「武」基线为 体 90 / 武 92，名将（抗倭、殉国等）再上调至 体 93 / 武 95。
> - 武举始于唐武则天长安二年（702 年），但唐、五代武状元无明确姓名记载（详见各节）；两宋、明、清武状元有可考者。
> - 数据源：维基百科各朝「状元列表」、百度百科、《登科记考》等；存在争议/存疑者如实收录，不确定年份标 `?`。
