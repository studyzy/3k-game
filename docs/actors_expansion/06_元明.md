# 元明人物表（蒙古帝国/元朝 · 明 · 英烈传）

> 说明
> - 本表为「三国之后 → 清末」人物扩展计划的第六个朝代批次，范围约 1206 年（成吉思汗建蒙古国）至 1644 年（明亡）。
> - 字段：姓名 / 字 / 出场(约) / 卒年(约) / 身份 / 出处。出场(约) = 首次见诸史书（有明确事迹）的年份，非出生年；卒年不详者标 `?`，约数标 `约xxx`。
> - 出处以正史为主（《元史》《新元史》《明史》《明实录》等），演义/小说人物单列并标注。
> - 蒙古、女真等族人物多元汉文表字，史书未载者字列标 `?`；明君主多以名行，无独立表字者标 `?`。
> - 明末降清人物（吴三桂、洪承畴、尚可喜、耿仲明、耿精忠、孔有德、祖大寿）与明末清初思想家（顾炎武、黄宗羲、王夫之）已归「清」文件，此处不收录；南宋降元将领吕文焕已归「两宋辽金西夏」文件，不重复。
> - 本阶段只整理人物与史实信息，能力估值（体/武/知/忠/德/政/统/胆）后续单独进行。

## 三、演义小说人物（《英烈传》）

> 注：《英烈传》为元末明初历史演义，其塑造的常遇春、徐达、花云、胡大海、郭英、沐英等皆有真实原型，已在上文「明初开国名将」表中收录并标注《英烈传》出处，此处不重复；纯小说增饰形象（如胡大海之黑脸、郭英之火龙枪等）不另立条目。
