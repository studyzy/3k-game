# 清人物表（后金 · 清，1616—1911）

> 说明
> - 本表为「三国之后 → 清末」人物扩展计划的最后一个朝代批次，范围约 1616 年（努尔哈赤建后金）至 1911 年（清帝退位）。
> - 字段：姓名 / 字 / 出场(约) / 卒年(约) / 身份 / 出场地 / 出处 / 体 / 武 / 知 / 忠 / 德 / 政 / 统 / 胆 / 军种。出场(约) = 首次见诸史书（有明确事迹）的年份，非出生年；出场或卒年不详者标 `?`。
> - 出处以正史为主（《清史稿》《清实录》《清史列传》等），公案小说人物单列并标注（《施公案》《彭公案》《儿女英雄传》）。
> - 满族君主、宗室及将领多元汉文表字，史书未载者字列标 `?`。
> - 明末抗清忠臣（袁崇焕、孙承宗、熊廷弼、卢象升、孙传庭、史可法、左良玉、曹文诏、秦良玉、郑成功、张煌言、黄道周、瞿式耜、李自成、张献忠、高迎祥等）已归「元明」文件，此处不收录。
> - 能力估值范围 1—99（忠可到 100）；军种：平（平地）、水（水军）、山（山地/骑射野战）。
