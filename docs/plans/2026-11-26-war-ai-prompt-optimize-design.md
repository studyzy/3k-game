# 战争场景 AI Agent 提示词重构（决策框架化）

日期：2026-11-26
范围：`agent-service/src/agent.ts` 的 `SYSTEM_PROMPT`（战争回合会话）。
不含：白兵战 `battle-agent.ts` 的 `BATTLE_SYSTEM_PROMPT`（另立待办）。

## 问题

现提示词 3418 汉字、十节「规则字典」，规则齐全但缺战术优先级。模型读完后知道所有规则，
却不知道「先算什么、什么该放弃、这局赢在哪」，表现为：平权用计、乱移动、把机动力花在低价值目标上。

## 目标

让 LLM 在每回合先完成「局面判定」，再按优先级择优，最终以消灭玩家、赢下战争为最高目标。

## 结构

`SYSTEM_PROMPT` 拆成 5 个常量按序拼接，各段单一职责：

| 段 | 职责 | 来源 |
|---|---|---|
| `PROMPT_ROLE` | 身份 + 工具基础约束 | 现有开头段，微调 |
| `PROMPT_STRATEGY` | 模式判定 + 优先级铁律 + 玩家套路 | 全新 |
| `PROMPT_TACTICS` | 地形与城门投资 | 全新 |
| `PROMPT_RULES` | 原一至十节规则字典 | 原样搬入，仅改冲突条目 |
| `PROMPT_OUTPUT` | 输出约束（reasoning 带模式标记） | 现有，改一条 |

导出名 `SYSTEM_PROMPT` 保留，trace 与测试不受影响。
首段必须仍含「战场指挥官」（`test/trace.test.ts:50/108` 断言）。

## 一、模式判定（`PROMPT_STRATEGY` 开头）

开场按 **side（attacker/defender，请求体已有）→ 粮草天数 → 兵力对比** 三步判定：

- 剩余天数 = `max_days - day`（攻方超期判负，守方守满判胜）。
- 粮草天数 = `rice / floor(总兵力/250)`，与剩余天数比。
- 三条路线择一：
  - **斩首**：玩家主将在场、兵力 < 1000、我方有武力 ≥ 85 的武将且 1~2 天内能摸到。
  - **强攻**：我方总兵力或白兵总战力明显占优，或粮草天数宽裕。
  - **磨盘**：反之；守方且天数富余时默认磨盘。
- 选一条主模式 + 一条备选；主模式前提消失立刻切换。
- **每次工具结果返回后重判**，切换必须写进 `reasoning`。

## 二、优先级铁律（每条附放弃条件）

杀主将 > 断粮 > 占太守府 > 抢城门格 > 白兵换损 > 用计控场 > 消耗 > 移动铺垫。

放弃条件举例：
- 斩首：摸不到就别行军两天去追，改为消耗。
- 断粮：只对攻方有意义；守方断粮先饿死自己。
- 占太守府：攻方才有即胜收益；守方靠「敌人踩上即败」被动防守即可。
- 抢城门格：只对「有兵且能活着站住」的武将成立，残兵站上去等于送。

## 三、地形与城门投资（`PROMPT_TACTICS`）

引擎依据（已逐条核对源码）：
- 白兵战地形取自**被攻击方**所在大战场格（`clBattleFight.gd:285-296`）；为 `walldoor` 时附加城门单位
  （`:509-530`）：3 个、位于 (9,4)(9,5)(9,6)、血量 = 城池城门耐久、受击免伤 1000（`attribute_set.json`
  小战场·兵种设定·城门）。
- 城门只挡横向：纵列上的城门单位会被跳过（`IUnitLogic.gd:131-132/285-286`）。
- 攻方绕到城门左侧，城门自动开门（`Battle_Auto_Run.gd:442-447`）。
- 城内侧用守城门阵（`attribute_set.json` 小战场·布阵 idx 4），站位在 x=6~8 后排。
- 弓：射击距离 4、待机必射、近身伤害 0.5（`attribute_set.json` 小战场·兵种设定·弓）。
- 城墙街区（`CITY_BLOCKS_CN`）免远程：`IWar_Attack.gd:66-67` + `effect_20242.gd:31`；
  隔墙打不穿（`IWar_Attack.gd:69`）；飞剑同样跳过（`war_auto_run.gd:1170`）。
- 撤退扣损豁免**只给大战场攻方**（`clBattleFight.gd:374/391/422`，难度≥3）。

写成规则：
- 守方 / 已占城方：把有兵武将移到 `城门` 格，这是白兵战城内方的入场券。
- 攻方：不要让主力长驻城门格（会变成城内方，但撤退扣损豁免只给大战场攻方）。
- 城墙格：只适合肉盾/残兵站，站上去自己也没了远程。

## 四、玩家套路（3 条）

- 玩家主将后撤保命 → 用定止/咒缚类控住，或改打副将持续消耗。
- 玩家拖时间 → 我是攻方时按剩余天数倒排，最后阶段不计损失换主将。
- 玩家堵路口 → 用远程隔墙消耗，或用仙军/逾墙类脱离。

## 五、输出（`PROMPT_OUTPUT`）

`reasoning` 改为 `【模式:强攻】一句话理由`。Godot 侧 `_show_reason`（`War_AI_behavior_llm.gd:313-317`）
原样显示，无需改 Godot。
