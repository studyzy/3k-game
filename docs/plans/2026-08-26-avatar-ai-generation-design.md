# 武将头像 AI 生成 · 可行性验证设计

日期：2026-08-26
状态：已确认，待实现

## 背景与目标

武将头像已独立化为每武将一个文件（`bwdl/packed/images/actor/face/avatar/{id}.png`）。人物库计划从三国跨朝代扩展到清末，需要大量新武将头像。本设计验证「用 AI 生成与现有 561 张头像风格神似的新头像」是否可行，产出能生成标准 256×40 八帧表情条的最小管线。

约束：
- 运行环境：本地 Mac（Apple Silicon / MPS），不训练 LoRA（太慢）。
- 达标标准：风格神似即可（非像素级 100% 一致）。
- 技术路线：AI img2img（已选定）。

## 头像图片的代码事实

| 项目 | 值 | 依据 |
|---|---|---|
| 路径 | `bwdl/packed/images/actor/face/avatar/{0..560}.png`（600 张 = 561 武将 + 39 占位） | `Actor_Helper.gd:1126` |
| 尺寸 | 256×40，RGBA，全不透明 | PIL 实测 |
| 帧布局 | 8 帧横向，每帧 32×40：`[mood0闭嘴, mood0张嘴, mood1闭嘴, mood1张嘴, …]` | `global.gd:1177-1191` |
| 渲染 | 静态显示取第 4 帧（`4*width`），动画轮播 8 帧 | `global.gd:1191` |
| 单帧高 | 40px | `Static_Manager.gd:1312` `ORIGINAL_AVATAR_PER_HEIGHT=40` |

## 关键洞察

1. **8 帧可简化成 1 帧**：实测「闭嘴→张嘴」仅差 33~75 像素（占 1280 的 2~6%），不同 mood 之间仅差 16~145 像素。即每张头像核心是 1 张 32×40 闭嘴脸，张嘴/换心情都是嘴、眼、眉的小幅改动，可用脚本派生。
2. **风格是「低分辨率像素画 + 丰富渐变」**：561 张去重后 12311 色，肤色系如 `(255,155,96)/(255,150,96)` 有轻微渐变，非 8-bit 纯色，但仍是 32×40 像素画骨架。

## 方案选型

排除：本地训练 LoRA（Mac 太慢）、ComfyUI（选脚本化 diffusers，可复现可批处理）。

选定 B：diffusers + SD 1.5 + 像素风 LoRA，img2img 为主。

## 设计

### 第 1 段：架构与选型

- 引擎：`diffusers`（Python 脚本）+ PyTorch MPS。
- 模型：SD 1.5 基础 + 像素风 LoRA（需日式像素风，避免欧美风跑偏）。
- 生成方式：img2img 为主，text2img 为辅。

管线 5 步：
1. 取第 4 帧（闭嘴 32×40）→ 最近邻放大到 512×512。
2. img2img 重绘（denoising 0.5~0.7）。
3. 输出缩回 32×40。
4. 调色板量化（映射到主色板）。
5. 铺 8 帧（闭嘴帧派生张嘴帧 + 4 组 mood）。

### 第 2 段：数据与模型准备

- 素材抽取：抽取每张第 4 帧存 `reference/{id}.png`，同时提取主色板（12311 色中位切分/K-means 聚成 32~64 色）。
- 模型选型：SD 1.5（`runwayml/stable-diffusion-v1-5` 或 `Lykon/dreamshaper-8`，~4GB）。像素 LoRA 日式 FC 风资源稀缺，先联网筛 1~2 个候选各跑 2 张对比；都不理想则退「低 denoising + 强像素提示词」。兜底 `PixelArt XL`（SDXL 系，~7GB，Mac 更吃力）。
- 网络：HF 走国内镜像 `export HF_ENDPOINT=https://hf-mirror.com`。

### 第 3 段：生成、后处理与验证

- img2img 参数：输入放大 512×512，`strength=0.55~0.7`，`steps=20~30`，prompt「日式像素风、三国武将、正面头像、纯色底」+ 可选特征词。
- 后处理：缩放 → 中位切分量化 → 32×40 闭嘴帧。
- 铺 8 帧分两步：先全复制闭嘴帧（可静态显示），再脚本派生张嘴帧 + 微调 4 组 mood。

## 目录结构

```
tools/avatar_gen/
  extract.py      # 抽取第4帧 + 主色板
  gen.py          # diffusers img2img
  post.py         # 缩放+量化+铺8帧
  reference/ output/
```

## 验证方式

生成 3~5 张新脸，与现有头像并排对比，输出到 `output/` 供人工查看。达标 = 风格神似、像素风保持、像三国武将。

## MVP 边界

先验证「能出风格神似的单帧脸」；铺 8 帧第二步属确定可行的工程活，不阻塞主验证。

## 风险

- 模型下载 4~7GB，需接受下载 + Mac 推理每张 10~30s。
- 日式像素 LoRA 稀缺，欧美风可能跑偏，需实测调。
